# Z80 Bits

This repository is a curated collection of optimized routines and programming techniques for experienced Z80 programmers.
Each document focuses on a single topic - whether a class of arithmetic routines, a clever optimization, or a useful
coding pattern. The goal is to collect high-quality Z80 code that is both efficient and elegant.

Z80 Bits is a spiritual continuation of an older [project](https://baze.sk/3sc/misc/z80bits.html), revived and gradually
cleaned up and expanded over time. Bug fixes, optimizations, corrections, and contributions are always welcome.
